# Vlixxo

[vlixxo.com](https://www.vlixxo.com) is an ecommerce storefront and product-discovery platform focused on a simple, reliable shopping experience.

## Public project profile

This repository is the public GitHub home for Vlixxo. It is intentionally limited to public-safe project information and documentation.

The production application source, infrastructure configuration, deployment credentials, supplier integrations, payment credentials, OAuth tokens, API secrets, webhook secrets, signing keys, database credentials, and private operational tooling are maintained outside this public repository.

## Security boundary

- No `.env` files or production configuration are committed.
- No private keys, certificates, access tokens, API keys, passwords, or service-account credentials are committed.
- No production database exports, customer data, order data, or internal logs are committed.
- Example configuration must use placeholders only.
- Any future code contribution should pass secret scanning before merge.
