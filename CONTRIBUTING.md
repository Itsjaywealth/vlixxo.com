# Contributing

Thank you for your interest in Vlixxo.

This public repository is intentionally limited to public-safe documentation and selected materials. Production application source and operational configuration are maintained privately.

## Before opening a contribution

- Do not include credentials, tokens, private keys or production environment values.
- Do not include customer, order, private analytics or internal operational data.
- Do not include private infrastructure endpoints or supplier/payment authentication details.
- Keep examples sanitized and use placeholders only.
- Run a secret scan before submitting changes when possible.

## Security issues

Do not disclose security vulnerabilities or credentials in a public issue. Follow [SECURITY.md](SECURITY.md) instead.
