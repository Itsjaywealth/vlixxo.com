# Public Storefront Screenshots

These images are captured only from public Vlixxo customer-facing pages.

They must not contain customer or order information, personal contact details, admin interfaces, private analytics, credentials, tokens or internal configuration.

Current captures include the public home, shop, categories and mobile storefront experiences.

## Regional display

Vlixxo is an international storefront. Prices, currency, delivery estimates and shipping messages are shown for the shopper's region, so the captures above reflect the regional view of the session they were taken in (for example, naira pricing and a Nigeria delivery banner). Shoppers in other supported markets see their own region's details.
